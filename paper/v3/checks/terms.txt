#   check ignores the note; it is printed with a hit. Patterns contain no TAB.
# - Case-sensitive unless the pattern starts with `(?i)`.
#
# SCOPE (what the check scans)
# - Main text only: paper/v3/sections/00_abstract.md through 12_conclusion.md
#   (files 13_* and later are the appendix and are NOT scanned), plus the
#   `title` and `description` in front_matter.yaml.
# - Captions, figcaptions, `<p class="caption">`, alt text, table cells and
#   listing LABEL paragraphs ARE scanned (they are main text).
# - Stripped before scanning: HTML comments (ledger tags, STUB-SPEC blocks,
#   LISTING lines, HOLE markers) and the bodies of fenced code blocks (listings
#   keep the code's own tags byte-identical; prose must not echo them).
#
# EXEMPTION (V3-S3: "Figure labels that cannot be rebuilt are glossed once")
# - A match is allowed when it sits inside a figure-label gloss of exactly the
#   form  labelled “TERM” on the figure  (curly quotes U+201C/U+201D), inside a
#   figure caption (figcaption or <p class="caption">). Each glossed term may
#   be glossed at most ONCE in the whole main text. Report the gloss count per
#   term so the mechanics reviewer can see them. If the owner agrees to the
#   label-only rebuilds (P2 R1–R11), the glosses go and the exemption should
#   then match nothing.
#
# The terms the glossary keeps but defines at first use (floor, bar, unblinding,
# grid, locked, co-active, sensitivity arm, fire-only, ...) are NOT here; see
